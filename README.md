# Як редагувати сайт F & Y Studio

Це готовий статичний сайт. Відкрийте `index.html` у браузері, щоб переглянути. HTML — це вміст і тексти, CSS — зовнішній вигляд, JavaScript — робота меню.

## Де що лежить

- `index.html` — головна сторінка, великий банер, опис студії, картка гри й анонс новин.
- `ігри.html` — каталог ігор. Копіюйте картку `<article class="content-card">` для кожної гри.
- `новини.html` — список новин. Копіюйте картку, змінюйте дату, заголовок, текст і посилання.
- `донат.html` — інформація про підтримку; замініть `href="#"` на адресу платіжної сторінки.
- `соцмережі.html` — канали студії; замініть `href="#"` на справжні адреси.
- `про-студію.html` — місія, команда й контакти.
- `css/style.css` — кольори, шрифти, оформлення карток, банер і мобільна версія.
- `js/main.js` — відкривання мобільного меню та підсвічування активної вкладки. Зазвичай змінювати не потрібно.
- `зображення/` — покладіть сюди свої фото, логотипи та обкладинки.

## Як замінити текст на головному банері

Відкрийте `index.html` і знайдіть коментар `ГОЛОВНИЙ БАНЕР`. Під ним:

- `eyebrow` — маленький напис над головним заголовком.
- `<h1>` — великий заголовок банера.
- `hero-lead` — короткий опис під заголовком.
- `hero-actions` — кнопки банера; змінюйте підпис кнопки та адресу в `href`.

## Як додати фото замість абстрактної ілюстрації банера

Зображення банера зараз намальоване CSS і знаходиться в блоці `hero-art` у `index.html`. Додайте файл, наприклад `зображення/банер.jpg`, а в цьому блоці вставте:

```html
<img class="hero-image" src="зображення/банер.jpg" alt="Короткий опис зображення">
```

Стилі банера шукайте в `css/style.css` за словами `hero-art`. Саме там можна налаштувати висоту, обрізання, затемнення та розташування зображення. Зображення гри на головній шукайте у блоці `game-card-art`; обкладинки каталогу — у картках `content-card` сторінки `ігри.html`.

## Як змінити кольори сайту

На початку `css/style.css` знайдіть `:root`. Там підписані змінні кольорів: `--bg` — фон, `--text` — основний текст, `--muted` — другорядний текст, `--pink` і `--lime` — акцентні кольори. Зміна цих значень оновить кольори по всьому сайту.

## Як змінити меню та підпис унизу

Меню є в кожному HTML-файлі під коментарем `МЕНЮ`. Змініть текст посилання та його `href` у всіх сторінках. Унизу кожної сторінки знайдіть коментар `ФУТЕР`; там міститься `© 2026 F & Y Studio. Всі права захищені.`.

У коді вже є українські коментарі з поясненням блоків. Позначені `#` адреси — тимчасові, замініть їх на свої. Зміни зберігайте, потім оновіть сторінку в браузері.
